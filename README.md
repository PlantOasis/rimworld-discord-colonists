# Discord colonists for RimWorld

Everyone's self-made colonist from the Discord, as **EdB Prepare Carefully** presets. Grab your own, or the whole crew, and drop them into any RimWorld 1.6 game.

## How to use one

1. Install [EdB Prepare Carefully](https://steamcommunity.com/sharedfiles/filedetails/?id=735106432) (and Harmony, which it needs).
2. Download the `.pcc` file(s) you want from the [colonists](colonists) folder (click the file, then the download button), or use **Code → Download ZIP** for all of them.
3. Put the files in your Prepare Carefully folder:
   - **Windows:** `%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\PrepareCarefully\`
   - **Mac:** `~/Library/Application Support/RimWorld/PrepareCarefully/`
   - **Linux:** `~/.config/unity3d/Ludeon Studios/RimWorld by Ludeon Studios/PrepareCarefully/`
4. Start a new colony. On the colonist screen click **Prepare Carefully**, then **Load** on a colonist slot and pick the name.

The characters use content from all five expansions (Royalty, Ideology, Biotech, Anomaly, Odyssey). Missing an expansion? Prepare Carefully will warn you and swap or drop the parts you don't own; the colonist still loads.
